# Новостной сайт на Laravel

Учебный проект новостного портала, разработанный в рамках практического задания.

## Разделы сайта

1. **Главная (`/`)** — общая лента всех опубликованных новостей.
2. **Каталог (`/catalog`)** — лента новостей фиксированной тематики («Искусственный интеллект»).
3. **Журналист (`/journalist`)** — форма создания и публикации новой статьи (поля «Заголовок», «Категория», «Текст статьи»).
4. **Администратор (`/admin`)** — панель администратора со статистикой и списком статей с возможностью удаления.

## Структура компонентов

- `resources/views/components/header.blade.php` — общая шапка сайта с навигационным меню из 4 разделов.
- `resources/views/components/footer.blade.php` — единый подвал сайта.
- `resources/views/components/news-card.blade.php` — компонент карточки новости (ID, тема, заголовок, текст, дата).
- `resources/views/components/layout.blade.php` — основной шаблон-обертка сайта.

## Запуск проекта

1. Запуск встроенного веб-сервера:
```bash
php artisan serve
```

2. Откройте в браузере:
[http://127.0.0.1:8000](http://127.0.0.1:8000)
