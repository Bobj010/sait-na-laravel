# Новостной портал на Laravel

Полнофункциональный учебный проект новостного портала, разработанный на фреймворке **Laravel 11 / 12** с использованием компонентной архитектуры **Blade** и базы данных **SQLite**.

---

## ⚡ Быстрый запуск в 1 клик

Для запуска на компьютере в колледже (Windows):
1. Скачайте проект или клонируйте репозиторий.
2. Дважды кликните по файлу **`start.bat`**.
3. Сайт автоматически откроется по адресу: **[http://127.0.0.1:8000](http://127.0.0.1:8000)**.

> Все тестовые пользователи (`admin@test.ru`, `journalist@test.ru`, `user@test.ru`, пароль: `12345`), категории и статьи уже предзаполнены в базе данных. На странице входа (`/login`) работают **кнопки быстрого входа в 1 клик**.

---

## 📌 Основные разделы сайта

1. **Главная (`/`)** — общая лента новостей с цветными бейджами рубрик, указанием автора публикации и панелью фильтрации по категориям.
2. **Каталог (`/catalog`)** — тематический каталог статей по выбранным категориям.
3. **Журналист (`/journalist`)** — страница публикации новых статей с выбором категории из базы данных (доступна ролям: `journalist`, `admin`).
4. **Администратор (`/admin`)** — панель управления: модерация (редактирование и удаление) новостей, статистика и смена ролей пользователей.

---

## 👥 Система ролей и доступ

* **Читатель по умолчанию**: любой гость сайта сразу имеет доступ к чтению всех новостей без обязательной регистрации.
* **Журналист (`journalist`)**: может публиковать новые статьи (авторство автоматически закрепляется за его учетной записью).
* **Администратор (`admin`)**: полный доступ к модерации контента и назначению ролей.

Разграничение доступа реализовано через кастомный `RoleMiddleware`.

---

## 🗄️ База данных и связи (Relations)

В проекте реализованы связи **«Один ко многим» (1:N)**:
* `Category hasMany News` / `News belongsTo Category` — каждая новость строго привязана к категории из таблицы `categories` (защита от подделки категорий на фронтенде).
* `User hasMany News` / `News belongsTo User` — статьи связаны по внешнему ключу `user_id` с их авторами.
