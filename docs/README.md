# Документация проекта: Новостной портал на Laravel
*Центральный хаб проектной архитектуры (Методология Vibecoding)*

Добро пожаловать в центр технической и продуктовой документации учебного новостного портала. Все документы структурированы по стандарту профессиональной веб-разработки:

---

## 📚 Навигация по разделам документации

| Документ | Для кого | Назначение |
|---|---|---|
| 📄 **[`PRODUCT_SPEC.md`](PRODUCT_SPEC.md)** | Для человека / студента | Продуктовая спецификация простым языком: философия «Читатель по умолчанию», 4 раздела, роли и пользовательские сценарии |
| 🛠️ **[`SPEC.md`](SPEC.md)** | Для разработчика / агента | Техническая спецификация: схемы таблиц БД, маршруты `routes/web.php`, контроллеры, middleware и безопасность |

## ⚡ Экспресс-справка: Команды терминала

```powershell
# Запуск сайта через батник (в 1 клик на Windows)
.\start.bat

# Ручной запуск сервера
php artisan serve --port=8000

# Запуск полного набора автотестов (8 тестов, 45 assertions)
php artisan test
```
