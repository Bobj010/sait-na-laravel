# Инструкция по запуску и развертыванию проекта (Setup Guide)
*Файл: `docs/SETUP.md` | Статус: Актуально*

---

## 1. Системные требования

* **Операционная система**: Windows 10/11, macOS, Linux
* **PHP**: Версия 8.2 или выше с включенными модулями `pdo_sqlite`, `mbstring`, `openssl`, `tokenizer`
* **Composer** *(опционально)*: Папка `vendor/` уже установлена для автономной работы
* **Веб-сервер**: Встроенный сервер PHP/Laravel (не требует Apache, Nginx или OpenServer)

---

## 2. Экспресс-запуск в 1 клик на Windows (Рекомендуется для колледжа)

1. Скачайте репозиторий с GitHub (как ZIP или через `git clone https://github.com/Bobj010/sait-na-laravel.git`).
2. В папке проекта дважды кликните по файлу **`start.bat`**.
3. Скрипт в автоматическом режиме:
   * Проверит файл конфигурации `.env` (при отсутствии создаст из `.env.example` и сгенерирует `APP_KEY`).
   * Проверит наличие базы данных SQLite и при необходимости накатит миграции и сиды.
   * Запустит веб-сервер на адресе **`http://127.0.0.1:8000`**.
4. Откройте в браузере: [http://127.0.0.1:8000](http://127.0.0.1:8000).

---

## 3. Ручной запуск через консоль (PowerShell / CMD / Bash)

Если запуск выполняется в терминале:

```powershell
# 1. Перейдите в рабочую папку
cd 'C:\Users\eduar\Desktop\Учеба\sait_na_Laravel'

# 2. Создайте файл конфигурации (если еще не создан)
if (-not (Test-Path .env)) { copy .env.example .env; php artisan key:generate }

# 3. Примените миграции и заполните тестовыми данными
php artisan migrate --force
php artisan db:seed --force

# 4. Запустите локальный сервер
php artisan serve --port=8000
```

На странице входа (`/login`) доступны **кнопки быстрого входа в 1 клик** (не требуют ввода пароля).

Если требуется ручная авторизация:
| Роль | Email (Логин) | Пароль | Права |

## 5. Запуск автотестов (TDD Verification)

Для проверки работоспособности всех модулей выполните:

```powershell
php artisan test
```

*Все 8 тестов (45 проверок) должны завершиться со статусом `PASSED` (100% зелёный результат).*

---

## 6. Решение типовых проблем (Troubleshooting)

* **Порт 8000 занят другой программой**:
  Запустите сервер на другом порту:
  ```powershell
  php artisan serve --port=8080
  ```
* **Ошибка «Пользователь не найден»**:
  В контроллере встроена защита `ensureUserExists()` — достаточно один раз нажать на кнопку быстрого входа, и пользователь будет создан автоматически. Либо выполните в консоли:
  ```powershell
  php artisan migrate:fresh --seed
  ```
