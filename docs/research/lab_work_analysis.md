# Анализ требований лабораторных работ колледжа (Лабы 0–4)
*Файл: `docs/research/lab_work_analysis.md` | Статус: Актуально*

Данный документ обобщает структуру и требования лабораторного практикума по разработке веб-приложения на Laravel.

---

## 📋 Карта лабораторных работ

```
Лаба 0: Установка и развертывание Laravel
   │
   ▼
Лаба 1: Вёрстка интерфейса и Blade-шаблонизация
   │
   ▼
Лаба 2: База данных, миграции и сидеры (SQLite)
   │
   ▼
Лаба 3: Роли пользователей, права доступа и Middleware
   │
   ▼
Лаба 4: Панель администратора, модерация контента и смена ролей
```

---

## Лабораторная работа 0: Установка Laravel и настройка окружения
* **Цель**: Развернуть каркас проекта на базе Laravel, проверить запуск локального веб-сервера.
* **Реализация в проекте**:
  * Использован Laravel 11/12 с поддержкой PHP 8.3.
  * Настроен файл `.env.example`.
  * Создан скрипт `start.bat` для мгновенного старта на Windows.
  * Сервер поднимается командой `php artisan serve --port=8000`.

---

## Лабораторная работа 1: Вёрстка страниц и Blade-шаблонизация
* **Цель**: Сверстать каркас страниц портала с соблюдением модульной структуры шаблонов.
* **Реализация в проекте**:
  * Создан базовый каркас `<x-layout />` с единым адаптивным CSS.
  * Выделена общая шапка `<x-header />` с 4 разделами (Главная, Каталог, Журналист, Администратор) и индикатором текущего статуса пользователя.
  * Выделен единый подвал `<x-footer />`.
  * Разработан переиспользуемый компонент карточки новости `<x-news-card />` (номер публикации `№ ID`, цветной бейдж темы, дата, заголовок, текст).

---

## Лабораторная работа 2: База данных, миграции и Eloquent ORM
* **Цель**: Спроектировать структуру реляционной базы данных, создать миграции, модели и сидеры.
* **Реализация в проекте**:
  * Выбрана автономная база данных **SQLite** (`database/database.sqlite`).
  * Миграция `create_news_table.php`: колонки `id`, `title`, `category`, `content`, `created_at`.
  * Eloquent-модель `News.php` с массовым заполнением `$fillable`.
  * Сидер `NewsSeeder.php`, наполняющий базу 5 начальными новостями по рубрикам: «Искусственный интеллект», «Технологии», «Космос».

---

## Лабораторная работа 3: Аутентификация, роли пользователей и Middleware
* **Цель**: Разграничить права доступа между категориями пользователей.
* **Реализация в проекте**:
  * Добавлена колонка `role` в таблицу `users` со значениями: `admin`, `journalist`, `user`.
  * Разработан собственный `RoleMiddleware.php`.
  * Реализована концепция «Читатель по умолчанию»: гостю открыты Главная и Каталог без авторизации.
  * На странице входа `/login` добавлены кнопки быстрого входа в 1 клик для демонстрации ролей.
  * Сидер `DatabaseSeeder.php` создает 3 пользователей с паролем `12345`.

---

## Лабораторная работа 4: Панель администратора и модерация
* **Цель**: Создать функционал редактирования/удаления контента и управления правами.
* **Реализация в проекте**:
  * Раздел `/admin` доступен только роли `admin`.
  * Сводные счетчики: количество новостей и авторов.
  * Модерация новостей: переход на страницу редактирования `/admin/news/{id}/edit` и удаление с подтверждением.
  * Управление ролями: прямое изменение роли любого пользователя (`admin`, `journalist`, `user`) через выпадающий список с сохранением в БД.
  * Защита от случайного снятия прав администратора с самого себя.
